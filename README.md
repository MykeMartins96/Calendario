
# 📅 Calendário Interativo

### Aplicação Front-End com HTML, CSS e JavaScript

O **Calendário Interativo** é uma aplicação web desenvolvida para visualizar datas e navegar entre diferentes meses, utilizando JavaScript para atualizar dinamicamente o calendário.

## 🎯 Problema e Solução

**Problema:** visualizar e consultar datas de diferentes meses pode exigir uma navegação prática e organizada.

**Solução:** um calendário digital interativo que permite avançar e voltar entre os meses de maneira simples.

## 📸 Preview

![Calendário Interativo](https://github.com/msm1996/Calendario/blob/main/Captura%20de%20tela%202025-10-28%20134251.png?raw=true)

## 🚀 Funcionalidades

- Visualização dos dias do mês
- Navegação entre meses anteriores e seguintes
- Organização dinâmica das datas
- Atualização automática do calendário
- Interface interativa e responsiva

## 🛠️ Tecnologias

**Front-End**
- HTML5
- CSS3
- JavaScript
- DOM

## 💡 Desafio Técnico

O principal desafio foi implementar a lógica de manipulação de datas com JavaScript, organizar corretamente os dias de cada mês e atualizar a interface dinamicamente durante a navegação.
